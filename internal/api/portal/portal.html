KMS 포털

이미 만들어진 키로 데이터를 암호화·복호화합니다. 키를 새로 만들거나 서버를 여는 기능은 여기 없습니다.

현재 서비스 점검 중입니다. 잠시 후 다시 시도해 주세요.

사용할 키

암호화에 사용할 키 이름을 선택하거나 직접 입력하세요.

암호화

평문을 입력하면 이 키의 최신 버전으로 암호화합니다.

복호화

이 키로 암호화된 암호문(kms:v...)을 붙여넣으면 원래 내용을 보여줍니다.

재암호화 (Rewrap)

관리자가 키를 회전시키면, 예전 버전으로 암호화된 데이터는 계속 복호화는 되지만 최신 버전이 아닙니다. 재암호화(Rewrap)는 평문을 노출하지 않고 암호문을 최신 버전으로 갱신합니다.

  1. 암호화 패널에서 얻은 암호문을 아래에 붙여넣으세요
  2. '재암호화' 클릭 → 최신 버전(kms:v{n}:...)의 새 암호문을 받습니다
  3. 이전 암호문 대신 이 새 암호문을 사용하세요
