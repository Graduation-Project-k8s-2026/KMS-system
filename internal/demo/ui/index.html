KMS 사용자 포털

키로 데이터를 암호화·복호화하고, 옛 암호문을 새 키 버전으로 옮겨 볼 수 있어요. 입력한 내용은 이 페이지를 떠나면 지워져요.

키마다 이 서비스 계정이 쓸 수 있는지는 KMS가 정해요. 권한이 없으면 아래에서 안내해 드려요.

이렇게 동작해요

  • 암호화: 문장을 키의 최신 버전으로 암호화해 kms:v{번호}:… 암호문을 돌려줘요. 번호가 암호화에 쓴 키 버전이에요.
  • 복호화: 암호문을 원래 문장으로 되돌려요. 관리자가 옛 버전을 차단했다면 실패할 수 있어요.
  • 새 버전으로 옮기기(rewrap): 원문을 보지 않고 암호문을 최신 키 버전으로 바꿔요. 옛 암호문 대신 새 암호문을 보관하세요.

파일 암호화 (브라우저 안에서)

파일은 이 브라우저 안에서 암호화·복호화돼요. 원문 파일은 서버로 보내지 않아요. 서버(KMS)에서는 1회용 데이터 키만 받아 와요. 결과 파일(.kmsf)은 명령줄 도구(kms decrypt)로도 풀 수 있어요.

브라우저 메모리를 쓰므로 1 GiB 이하 파일만 지원해요. 큰 파일은 명령줄 도구를 쓰세요. 이 포털은 tailnet 전용 시험 도구예요.

Transit API 사용 가이드

앱은 자기 서비스 계정 토큰으로 KMS의 Transit API를 직접 불러요. 아래 <TOKEN>, <KMS_URL>은 자리표시자예요. 실제 토큰은 화면이나 문서에 적지 마세요.
